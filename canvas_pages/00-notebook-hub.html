Submitting a homework notebook

  1. Open the notebook, then immediately do File > Save a copy in Drive. Work in your copy.
  2. Answer written questions in the markdown cells marked Your answer: (double-click the cell to edit).
  3. Run every cell before you submit.
  4. Download it: File > Download > Download .ipynb.
  5. Upload that .ipynb file to the matching Canvas assignment.
